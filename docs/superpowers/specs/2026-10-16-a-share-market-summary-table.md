# A 股日度全市场概览表

**日期：** 2026-10-16
**状态：** 已确认，实施中
**范围：** 完善“今日 A 股行情”回答：展示四个主要指数的单日行情、上一交易日对比，以及全市场成交/广度/涨跌停摘要；同时修复单日指数表格和重试原文提取。今日复盘指数使用服务端固定的 AkShare 日线操作，避开已实测返回腾讯 WAF HTTP 501 的 K 线端点；其他期限行情、周度复盘、个股行情或事件归因不扩展。

## 1. 业务对象与用户任务

用户需要快速判断当日大盘方向、成交活跃度、市场参与广度和涨跌停极端分布。此回答对应一个**有明确数据日期与截至时间的 A 股交易日快照**，不是日历日预测，也不是对行情原因的推断。

本次数据对象：

- 四个指数：上证综指、深证成指、创业板指、科创 50；展示收盘值、涨跌点数及相对该指数上一根交易日 K 线的涨跌幅。
- 全 A 股票快照：上涨、下跌、平盘家数，成交额/量和加权量比。
- 涨停、跌停家数：按数据源当日完整涨跌停池统计；若覆盖不足或日期不匹配则显示不可用，不以 MCP 的截断样本数代替全市场总数。

## 2. 已确认口径

- **对比标签：**“较上一交易日”；不按自然日取前一天，节假日由数据源的前一根交易日记录处理。
- **全 A 量比：** 对全市场快照中成交量与个股量比均为有效正值的股票，按成交量加权：`sum(成交量) / sum(成交量 / 个股量比)`。仅当有效量比样本覆盖至少 95% 的有效成交股票时给出汇总值；同时披露样本数/有效成交股票数。分母无效或覆盖不足时留空并说明原因。
- **股票范围：** 以全市场快照返回的 A 股证券为总体；涨跌家数与量比使用同一份快照，展示返回/去重/可分类行数。涨跌停数字严格称为“数据源池返回数”，接口未提供独立总量证明，不能声称经过跨源完整性验证。
- **今日指数来源：** 固定调用 `akshare.index_zh_a_hist` 查询四个服务端白名单指数；只请求包含目标日与前序交易日的窄日历区间，保留前序交易日用于涨跌比较。日期与代码由服务端生成，不接受模型参数。因已确认腾讯 K 线返回 WAF 501，今日复盘不再重复请求该端点；其他期限沿用原 Tencent 路由。
- **缓存/时限：** 全市场接口实测较慢，采用同进程 single-flight、同交易日 15 分钟缓存和 80 秒等待上限。实际冷缓存链路在指数取数与全市场快照完成后仍于普通问答 120 秒整轮上限到期、未生成回答，因此仅对模型识别为 broad-market recap 的请求使用 180 秒有界时限；其他普通问答仍为 120 秒，研究任务仍为 300 秒。盘中快照使用服务端最新指数交易日对齐；`as_of` 表示快照获取时间（提供方不返回独立时戳），不跨交易日复用。超时会以不可用产物降级，后台获取可继续完成并预热缓存；不伪造或沿用旧日期数据。
- **表格：** 单个交易日也可渲染指数及市场摘要表；缺少上一交易日 K 线时仍显示当日值，对比格标“不可用”。重试使用原始问题，不使用包含 UI 时间戳的气泡文本。

## 3. 信息结构

一个语义化表格按“指数行情 / 全市场概览 / 涨跌停”分组，列出项目、当日数据、较上一交易日（仅指数可用时填写）及数据口径/截至时间。表后仅给基于表中事实的简短概述；不在数据不足时推断原因。桌面与移动端沿用现有聊天行情表样式，保留可读表头、键盘可访问结构和窄屏换行。

## 5. 真实性与来源约束

现场探测发现：腾讯 K 线 `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get` 返回 HTTP 501 并跳转腾讯 WAF；AkShare `index_zh_a_hist` 对 `000001`、`399001`、`399006`、`000688` 均返回 2026-10-16 与前一日记录，四次请求约 21 秒；实施后再次调用 `load_a_share_index_kline("sh000001", 2026-10-06至2026-10-16)`，实际返回 7 根日线，最新日期为 2026-10-16。另一次全市场探测中 `stock_zh_a_spot` 返回约 5,576 行，用时约 8.1 秒；AkShare `stock_zh_a_spot_em` 快照约用 68 秒。2026-10-16 实际汇总探测返回 5,923 条证券记录、5,923 个去重代码，其中仅 5,567 条可分类，故不输出上涨/下跌/平盘计数，并将快照标为 partial；有效成交股票 5,567 条中有 5,566 条量比可用（99.98%），成交量/成交额因总体字段缺失仍不可报；涨停/跌停池返回 59/10 条。该次快照获取时间为 14:55:18+08:00，代表盘中快照而非收盘定稿。stock-data-mcp 暴露 43 个工具，但没有可直接提供全市场广度及全市场量比汇总的工具；现有复盘路径的涨跌停池调用存在 50 行上限。冷缓存真实接口回放 run `8294e22ad81343c380591fa499c67511` 取回四指数日线和 partial 市场快照，但在普通 120 秒整轮上限内未能完成答案生成；该证据促成 broad-market recap 单独采用 180 秒有界时限。上述均为本机单次探测，不代表提供方 SLA、稳定性或长期覆盖保证。AkShare 快照函数未提供证券总量/行情时间字段；实现需显式展示来源返回、有效分类及获取时间。`stock_market_activity_legu()` 当前探测失败，不能作为回退来源。

缺少当日、日期不一致、超时、无效字段或无法证明完整覆盖时，返回 partial/不可用并保留来源与原因。禁止将样本计数标作全市场、将旧日期数据冒充当日，或由模型补造行情数字。客户端无法控制提供方、参数、证券代码或查询日期。

## 7. 验收标准

1. 单日四指数行情生成表格；对比使用上一交易日而非前一自然日。
2. 全市场快照正确汇总上涨/下跌/平盘、成交额/量与指定加权量比；样本数、日期、来源可见。
3. 四个 AkShare 指数日线均返回请求日记录时，生成当日行情及上一交易日比较；数据缺失则不猜测。
4. 超时、空结果、日期不符、分母无效及覆盖不足均诚实降级，不产生虚构汇总。
5. 涨跌停池截断时不显示为全市场计数。
6. 重试请求精确等于用户原始问题，无消息时间戳。
7. 旧版 AnswerRun/消息仍可读取；同一“今日 A 股行情”请求的集成回归、聚焦单测及浏览器验证通过。
