# 移除研究记忆与研究决策设计

**状态：已确认，待编写实施计划**  
**日期：2026-09-18**

## 目标

移除可信问答中的“保存证据到研究记忆”和“保存研究决策”能力，并清理其本地持久化数据。研究工作台保留筛选、收藏、打开回答、编辑重问、分支追问、导出和质量观测。

## 用户确认的范围

用户明确选择完整删除：

- 不再提供保存事实证据、保存工具证据或保存研究决策的入口。
- 不再展示、读取或撤销已保存研究记忆。
- 清理现有本地 `data/research_memory.json`。
- 不保留只读历史记忆页，也不保留兼容 API。

该移除是破坏性变更：已有研究记忆和决策不可恢复；不会影响 AnswerRun、ResearchRun、研究工作台元数据、收藏、导出或质量摘要。

## 方案

### 后端与持久化

1. 删除 `webapp/research_memory.py` 及其仅服务于记忆的模型、请求体、引用和测试。
2. 从 `webapp/server.py` 移除研究记忆存储初始化、锁、owner 辅助函数及以下路由：
   - `GET /api/research/memory`
   - `POST /api/research/memory/facts`
   - `POST /api/research/memory/artifacts`
   - `POST /api/research/memory/decisions`
   - `DELETE /api/research/memory/{entry_id}`
3. 移除删除会话时“保留研究记忆数量”的计算和响应字段；删除会话不再读取记忆侧车。
4. 在应用启动的本地清理步骤中，仅删除默认路径 `data/research_memory.json`（若存在）。删除失败必须记录简短诊断并使启动失败，避免声称完成清理但保留可访问旧数据。该文件不在仓库中；不删除任何其他 `data/` 文件。
5. 保留 `webapp/evidence_identity.py`、稳定 `Fact.id` 和导出/评测对证据身份的使用；它们不依赖研究记忆，继续用于可信导出和离线质量评测。

### 前端

1. 从研究工作台移除事实的“保存证据”操作、研究运行的“保存研究决策”操作、研究记忆面板、撤销按钮和研究决策对话框。
2. 移除对应事件绑定、API 请求、刷新逻辑、状态提示以及仅用于该能力的 CSS。
3. 保留工作台即时刷新：收藏及其余工作台操作继续使用既有可见性和 request generation 防竞态保护。
4. 不修改导出、质量状态、事实/证据展示和其余聊天功能。

### 测试与 fixture

1. 删除或替换研究记忆单元/API/浏览器测试；不保留对已删除 API 的兼容断言。
2. 浏览器 fixture 不再创建 `ResearchMemoryStore` 或预置研究决策；浏览器回归断言工作台不存在记忆面板、保存证据、保存决策及撤销操作。
3. 增加启动清理测试：临时默认数据目录中存在 `research_memory.json` 时启动后文件被删除；非目标数据文件保留。清理失败路径必须可测试。
4. 保留并运行与工作台、导出、证据身份、质量评测和会话删除直接相关的回归。

### 文档

合入 `main` 后更新：

- `README.md`：移除研究记忆/决策的用户说明。
- `docs/FEATURE-CATALOG.md`：移除 API、侧车、关键不变量和测试入口，记录破坏性移除。
- `docs/superpowers/DESIGN-REGISTRY.md`：将本设计的状态按实际合并证据更新为“已实现”。

## 非目标

- 不删除研究工作台、收藏、导出、研究计划、编辑重问、分支追问或质量观测。
- 不删除稳定 Fact ID 或共享证据身份模块。
- 不迁移或导出被删除的记忆数据。
- 不添加新依赖、后台清理任务、自动交易、主动监控/推送或任何 M5 范围。

## 验收标准

1. UI、API、服务初始化和测试 fixture 中均无研究记忆/研究决策保存能力。
2. 本地 `data/research_memory.json` 在启动时被精确删除，其他数据文件不受影响；无法删除时服务不得伪装为已清理。
3. 工作台的剩余操作、导出、质量观测、Scope/owner 边界和不可变运行证据语义不回归。
4. 相关单元/API/浏览器测试、全量 pytest、`git diff --check` 和 CSS 检查通过。
5. 不提交侧车、下载、截图、浏览器或临时清理产物。

## 风险

- 该变更永久删除现有本地研究记忆和研究决策；用户已明确选择清理。
- 后端路由移除是破坏性 API 变更；本项目为本地单用户应用，未提供外部兼容层。
- 启动阶段清理不可静默忽略权限错误，否则旧数据可能残留并与已移除 UI/API 的产品承诺矛盾。
