# 移除研究记忆与研究决策 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完整移除研究证据/决策保存与研究记忆，同时精确清理本地旧侧车，保留研究工作台其余能力。

**Architecture:** 删除记忆存储模块、路由和前端表面，而不是仅隐藏按钮；应用启动时对默认 `data/research_memory.json` 执行唯一、可验证的清理。稳定 Fact ID 与共享证据身份仍保留给导出和离线质量评测，工作台仍只依赖 AnswerRun/ResearchRun 与 workspace 侧车。

**Tech Stack:** Python 3、FastAPI、pytest、原生 JavaScript、CSS、agent-browser。

**Spec:** `docs/superpowers/specs/2026-09-18-移除研究记忆与决策设计.md`

## Global Constraints

- 不新增第三方依赖。
- 不持久化或展示模型推理链。
- 不扩权或弱化 Scope、ToolPolicy、run/session owner、不可变 AnswerRun/ResearchRun 证据语义。
- 不实现自动交易、主动监控/推送、未确认投资建议或 M5 范围。
- 质量评测仅回放版本化 fixture，不调用真实 AI、MCP、网页、生产数据，且不在 API/服务启动时运行。
- 这是破坏性变更：删除现有 `data/research_memory.json`，不迁移、不导出历史研究记忆或决策。
- 不修改工作台筛选、收藏、打开回答、编辑重问、分支追问、导出、质量观测、稳定 Fact ID 或共享证据身份。
- 不提交侧车、下载、截图、浏览器或临时清理产物。

- [ ] **Step 3: 最小化移除实现**

在 `webapp/server.py`：

```python
def _remove_legacy_research_memory_sidecar() -> None:
    path = DATA_DIR / "research_memory.json"
    try:
        path.unlink(missing_ok=True)
    except OSError as exc:
        raise RuntimeError("无法清理已移除的研究记忆数据") from exc
```

在应用开始服务前调用该函数。移除 `ResearchMemoryStore`、`run_evidence_ids`、`research_memory`、`_research_memory_lock`、`_memory_store_for_owned_run`、所有记忆路由以及删除会话中记忆枚举/`retained_memory_count`。删除 `webapp/research_memory.py` 和只测试该模块的文件；使删除会话返回只包含仍有意义的删除结果。
