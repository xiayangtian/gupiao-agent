# 智能问答可信 Agent M4 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将会话升级为可筛选、可复核、可导出的研究工作台，并建立可重复运行的金融问答评测与运行质量体系。

**Architecture:** M4 不改变 M1–M3 的事实与执行真相，只建立索引、用户显式保存的研究记忆、导出视图和评测观测。`ResearchWorkspaceStore` 为既有 ChatStore 生成非破坏性索引；`ResearchMemoryStore` 仅接收用户显式确认的 Fact/Artifact/Decision；`ResearchExporter` 从持久化 AnswerRun/ResearchRun 生成可复核纪要；`ChatEvaluation` 读取固定用例，测量范围、引用、时间、状态和工具策略。前端将会话列表从标题列表升级为研究资产浏览器。

**Tech Stack:** Python 3.12、JSON 持久化、FastAPI、现有 ChatStore/TaskManager、原生 JavaScript、pytest、agent-browser。

**Spec:** `docs/superpowers/specs/2026-09-10-智能问答可信Agent升级-design.md`

## Preconditions

- M1–M3 均已上线：会话含 Scope/Artifact/AnswerRun，M2 含 Fact/VerificationReport，M3 含 ResearchRun。
- 不存在“自动写入长期记忆”的旧路径；用户保存动作可明确建模。
- M4 不实现自动交易、主动监控推送或未经用户确认的个体化投资建议。

## Global Constraints

- 工作台所有筛选基于持久化元数据（公司、行业、报告期、意图、状态、更新时间），不得仅靠标题关键词推断。
- 收藏、导出和研究记忆必须引用已有 immutable AnswerRun/Fact/Artifact；不得复制后改写原始证据。
- 只有用户显式点击“保存到研究记忆”的已验证 Fact/Artifact 或明确 Decision 才可写入记忆；`reference/conflict/unavailable` Fact 与 stopped 残片不可保存为确认事实。
- 导出必须包括范围、运行状态、事实、证据、外部数据截至时间、冲突和验证状态；不得仅导出模型正文。
- 会话/记忆删除必须可确认、可追踪且不删除原始 PDF；删除会话不自动删除用户单独保存的研究记忆，界面必须说明。
- 评测集不能调用真实 AI、MCP、网页或生产数据；使用受控 fake provider 和版本化 fixture。
- 指标只记录必要的匿名运行元数据，不记录密钥、完整外部原文、模型推理链或未授权个人信息。
- 不新增第三方依赖；`data/research_workspace.json`、`data/research_memory.json` 和 `data/chat_metrics.json` 必须加入 `.gitignore`。

## M4 Completion Definition

1. 用户可按持久化公司、行业、期间、意图、状态和收藏筛选研究资产；
2. 收藏、导出和记忆均可回到不可变 Scope/Fact/Artifact；
3. 未验证/冲突/停止残片不能保存为确认事实；
4. 导出完整表达范围、证据、外部数据时间、冲突和运行状态；
5. 删除会话不删除独立研究记忆且界面有明确披露；
6. 评测质量门槛可离线重复运行，发现 Scope 泄漏、伪页码、外部无时间、停止伪完成等问题即失败；
7. 全量、API、浏览器、移动端和评测验收通过；
8. 代码评审无 P0/P1，未引入自动交易或未经设置的持续监控。
