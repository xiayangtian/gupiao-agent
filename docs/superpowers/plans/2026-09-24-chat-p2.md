# 智能问答可靠性优化第二阶段实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Use TDD and finish each task with its specified focused verification before starting the next task.

**目标：** 让问答中的公司身份、财报范围、自然语言时间、复盘来源覆盖、数值证据和普通常识模式一致且可复核。

**架构：** 在 P1 的 Scope、ExecutionPlan、SourceRuntime、Fact 和 AnswerRun 合约上增量扩展。服务端确定身份、路由和时间窗口；来源只执行冻结参数；事实核验要求公司/指标/口径/期间/单位及来源类型匹配；常识回答独立标记，不共享财报数字的证据豁免。按范围解析、窗口/复盘、数字闭环、通用知识、集成验收五个可独立测试的工作流顺序实施，最后作为一个 P2 阶段统一验收。

**技术栈：** Python 3.12、现有 dataclass/FastAPI/SSE、现有 Tencent 与 MCP 客户端、pytest、原生 JavaScript、agent-browser；不新增运行依赖或行情提供方。

**设计：** `docs/superpowers/specs/chat-reliability-p2.md`

## 全局约束

- 只实施 TASK-20260924-004；不得修改 P3 异步/取消/研究路由或 P4 评测/检索优化。
- 公司身份必须来自既有 `stock_index`/`_resolve_symbol_code` 或已选报告；歧义、不存在或解析不可用时不能退到全库。
- 公司明确而报告集合为空时，Scope 保留公司且报告 ID 为空；行情和财报检索权限分别判断。
- 财报经营趋势、证券行情、市场复盘和普通常识由服务端确定性路由；模型计划不能改变意图、公司、时间、工具参数或预算。
- 日期固定按 `Asia/Shanghai` 解释；上周/本周按自然周筛实际日线，近五交易日使用实际返回的交易日；缺失数据不能补造或静默扩大窗口。
- 复盘仅用现有授权来源。最多 50 条的涨跌停池不代表完整总量；行业资金流不代表全市场资金流；完整广度无来源证据时标记不可用。
- 数值论断按公司、指标、单位、口径、期间/窗口匹配；派生事实须按固定公式并保留全部底层证据。不能因扩充正则而把无证据声明为通过。
- 普通知识标记“依据模型常识，未检索外部来源”；公司财务和行情事实始终需要来源支持。时效性事实不能由模型记忆冒充最新。
- 保持 P1 的 source runtime 权限/预算、AnswerRun 历史兼容、SSE 和终态不变量；不保存原始 provider 返回体、提示词或内部参数。
- 所有新测试使用固定时钟、假 provider 和确定性模型替身；测试不得隐式访问外网或真实模型。
- 不操作生产账号、不推送远端。用户已确认本计划并授权开始 P2 实施。
- **已确认预算：** 用户授权复盘最高 7 次市场调用/9 次总调用；网页仍最多 2 次。默认配置更低时取更小值，SourceAccess 仍决定来源是否获准；提高预算不增加 ToolPolicy 的模型工具权限。最多 7 次市场调用的组合是四次 Tencent 指数日线 + 两个涨跌停池 MCP + 一次行业资金流 MCP；不再重复调用单指数 `index_prices`。

**接口：**

```python
from dataclasses import dataclass
from datetime import date
from typing import Any, Literal, Mapping

@dataclass(frozen=True)
class QuestionRoute:
    intent: Literal["report_fact", "financial_trend", "market_quote", "market_trend", "market_recap", "general_knowledge", "general_web", "clarification"]
    requires_company: bool
    requires_time_window: bool

@dataclass(frozen=True)
class MarketWindow:
    label: str
    kind: Literal["calendar_week", "rolling_trading_days", "explicit"]
    start_date: date | None
    end_date: date | None
    trading_days: int | None
    timezone: str = "Asia/Shanghai"

@dataclass(frozen=True)
class WindowSelection:
    bars: tuple[Mapping[str, Any], ...]
    requested_label: str
    covered_dates: tuple[str, ...]
    status: Literal["complete", "partial", "unavailable"]
```

`QuestionRouter.classify(question) -> QuestionRoute` 使用服务端确定性词法/实体规则，与已有工具权限 `IntentRouter` 分离；普通财报事实归 `report_fact`（公司必需、时间可按可用报告披露），经营趋势归 `financial_trend`（公司与期间必需）。`resolve_financial_period(question) -> str | None` 只接受显式年月/季度/年度或明确滚动年限，返回可审计的原始/规范期间表达；趋势请求缺期间则澄清。`resolve_market_window(question, now) -> MarketWindow | None` 只解析用户表达，不访问 provider；`select_market_bars(rows, window) -> WindowSelection` 只使用来源实际返回且日期有效的行。日线 handler 每次按有界数量取数据，再由选择器筛自然周；滚动五交易日按日期排序取最近五条，少于五条返回 partial。行情/财报分析要求时间范围但无法解析时返回 clarification；仅点时“最新行情”可使用来源实际 as_of。财报/行情 route 不得因缺公司或时间执行 whole_corpus/无窗口调用。
