# P0 可靠性修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复季度报告身份冲突，持久化 Web 分析任务，并为财务指标增加结构化事实和程序校验，同时保持现有接口兼容。

**Architecture:** 报告身份集中到无状态辅助模块，RAG manifest 通过版本迁移淘汰无法判定归属的旧季度向量；任务执行仍使用线程池，但状态读写委托给 SQLite；指标抽取结果先进入独立事实校验器，再生成兼容的 `metrics`。

**Tech Stack:** Python 3.12、dataclasses、标准库 `sqlite3`、FastAPI、ChromaDB、pytest。

**Spec:** `docs/superpowers/specs/2026-08-30-P0可靠性修复设计.md`

## Global Constraints

- 保持现有 CLI、Web API、Markdown 报告和 JSON `metrics` 字段兼容。
- 不增加第三方依赖；不猜测旧季度文件或旧向量的归属。
- 中断任务不得自动重新调用模型。
- 所有生产代码必须先有能够正确失败的测试。
- 不修改用户已有的 `README.md` 和 `THIRD_PARTY_NOTICES.md` 变更。
- 不推送远程；最终 Git 整理由用户后续指令决定。

```python
def build_report_id(code, period, report_type=None):
    period_date = date.fromisoformat(period) if isinstance(period, str) else period
    resolved = report_type or (
        ReportType.SEMI_ANNUAL if period_date.month == 6
        else ReportType.QUARTERLY if period_date.month in (3, 9)
        else ReportType.ANNUAL
    )
    value = resolved.value if isinstance(resolved, ReportType) else str(resolved)
    return f"{code}:{period_date.isoformat()}:{value}"
```

```python
def test_completed_task_survives_manager_restart(tmp_path):
    db = str(tmp_path / "tasks.sqlite3")
    first = TaskManager(db_path=db)
    task_id = first.submit(lambda: {"answer": 42})
    assert _wait_status(first, task_id, ("done",))["result"] == {"answer": 42}
    first.shutdown()
    second = TaskManager(db_path=db)
    assert second.get(task_id)["result"] == {"answer": 42}
    second.shutdown()

def test_running_task_becomes_retryable_failure_after_restart(tmp_path):
    db = str(tmp_path / "tasks.sqlite3")
    store = TaskStore(db)
    store.create("interrupted")
    store.update("interrupted", status="running")
    store.close()
    manager = TaskManager(db_path=db)
    task = manager.get("interrupted")
    assert task["status"] == "failed"
    assert task["retryable"] is True
    assert "服务重启" in task["error"]
```
