# 财务结构可视化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为重新分析后的财报在利润、资产负债、现金流主题中提供可核验的本期结构图与精确数据表。

**Architecture:** 后端引入独立的 v4 `visualizations` 契约和白名单校验器；结构抽取器仅从当前报告期、合并口径的 PDF 文本证据中生成带页码引用的数据行，缺失时安全降级。前端将卡片动态匹配至对应主题 Tab，用 Chart.js 生成三类图形，并以原生数据表作为精确读数和无障碍替代。

**Tech Stack:** Python 3.12、dataclasses、现有 EvidenceRecord/EvidenceReference、FastAPI 既有流式状态、原生 JavaScript、Chart.js、pytest、agent-browser。

**Spec:** `docs/superpowers/specs/2026-09-10-财务结构可视化-design.md`

## Global Constraints

- 仅使用当前报告期、合并口径、带正整数 PDF 页码的 `pdf_text` 证据；不从结论文案、OCR、网页或内部结构化来源作图。
- 金额统一为亿元；不得反推、补算或混合报告期/口径。
- 仅新分析/重新分析产出 v4；旧 v2/v3 报告保持可读，显示重新分析提示，不自动重分析。
- 每张卡片至少两个有效核心指标才绘图；`partial` 显示已核验项，`unavailable` 不创建 canvas。
- 图表不进入快速结论；主题内顺序固定为标题/状态、图、语义表格、原有分析段落。
- 证据入口只显示 PDF 页码，沿用 `data-evidence-page` 和现有 PDF `?jump=…#page=N` 跳转。
- 移动端不得产生横向页面溢出；图表颜色不单独表达现金流正负。
