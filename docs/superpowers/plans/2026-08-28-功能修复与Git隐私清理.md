# 功能修复与 Git 隐私清理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复聊天会话串线、配置优先级、敏感信息扫描和 PDF 下载完整性问题，然后将本地 Git 历史重构为一个可安全推送的根提交。

**Architecture:** 保持现有 FastAPI 和单进程组件结构，只在问题边界做小范围修正。会话层分离“显式预建空会话”和“未指定 ID 时开始新对话”；AI 配置仅由 Python 客户端合并；敏感扫描以匹配值而不是整行判定豁免；PDF 使用同目录临时文件原子落盘。

**Tech Stack:** Python 3.12、FastAPI、pytest、requests、Bash、Git

**Spec:** `docs/superpowers/specs/2026-08-28-功能修复与Git隐私清理设计.md`

## Global Constraints

- 保留现有未提交功能，不回退用户工作树。
- 本轮不大规模拆分 `webapp/server.py` 或 `webapp/static/app.js`。
- AI 配置优先级固定为构造参数 > 环境变量 > `config.yaml` > 默认值。
- 最终 Git 提交保留用户现有作者身份。
- 功能修复验证通过前不重写 Git 历史。
